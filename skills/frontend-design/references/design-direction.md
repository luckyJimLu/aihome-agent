# Design Direction Reference

Use this reference when a redesign needs stronger visual identity or clearer hierarchy.

## Start with the product

Identify:

- the primary user,
- the primary task,
- the information users need first,
- the emotional tone appropriate to the product,
- the level of density appropriate to the workflow.

A routing/configuration product such as LLMFreeway should communicate control, status, trust, cost awareness, and diagnosability before decorative personality.

## Establish hierarchy

Create a clear order of attention:

1. current state or primary task,
2. primary action,
3. important supporting metrics/status,
4. secondary configuration,
5. explanatory metadata.

Use size, weight, spacing, placement, and contrast together. Do not rely on color alone.

## Typography

- Use a small, intentional type scale.
- Reserve strong weight/size differences for meaningful hierarchy.
- Keep body text readable at normal browser zoom.
- Prefer concise labels and headings.
- Use tabular numerals for values that users compare vertically when supported.

## Spacing and density

Choose a consistent spacing rhythm and reuse it.

- Group related controls tightly enough to read as one unit.
- Separate unrelated sections with stronger spacing rather than extra borders.
- Dense administrative interfaces may be compact, but never cramped.
- Avoid filling every empty area simply because space exists.

## Surfaces

Use surfaces only when they communicate grouping, state, or depth.

Avoid:

- turning every section into a card,
- nested cards without semantic purpose,
- excessive border/radius/shadow combinations,
- decorative glass effects that reduce legibility,
- gradients used as a default visual shortcut.

## Color

Use color to communicate:

- action,
- status,
- selection,
- warning/error,
- meaningful categorization.

Keep neutral surfaces dominant when users must scan technical information. Strong accent colors should have a job.

## Icons

Prefer the project's existing Lucide icon set.

- Pair unfamiliar icons with labels.
- Keep icon weight/size consistent.
- Do not use icons merely to fill visual space.

## Motion

Use motion for state transitions, feedback, or spatial continuity.

Avoid decorative animation that competes with the task. Respect reduced-motion preferences.

## Anti-generic check

Before finishing, ask:

- Could this screen belong to any random SaaS product?
- Are there too many interchangeable cards and pills?
- Is the primary task obvious without reading every label?
- Does the visual system reinforce LLMFreeway's routing/cost/status concepts?
- Is there one coherent design language rather than several trendy effects?
