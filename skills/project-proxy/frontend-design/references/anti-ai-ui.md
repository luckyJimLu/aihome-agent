# Anti-Generic UI

Remove generic AI-generated styling that conflicts with `DESIGN.md`.

Avoid by default:
- purple/blue gradients without semantic need,
- glow-heavy dark themes,
- glassmorphism,
- cards-inside-cards,
- oversized radii/shadows,
- decorative KPI grids,
- badges/pills without state meaning,
- repeated icon tiles before every heading,
- marketing hero copy,
- terminal/map/log decoration unrelated to the task.

Prefer clear labels, native controls, whitespace, borders, restrained surfaces and the established household connection metaphor.
