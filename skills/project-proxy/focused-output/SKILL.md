# Focused Output

Use only on explicit request.

Put the answer/next action first. Bound multi-step user actions. Keep one active thread. Make completion/progress visible. Report errors as location -> cause -> fix. Group long findings by priority.

System requirements, safety/privacy, repository contracts, evidence, validation and explicit deliverables always outrank presentation brevity. Do not infer any user condition, assume hidden session persistence, promise background work or invent duration estimates.
